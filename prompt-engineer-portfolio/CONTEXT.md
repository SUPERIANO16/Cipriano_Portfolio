# Portfolio Context

A web application serving as a frontend developer internship portfolio.

## Language

**Technical Minimalist**:
The core aesthetic direction of the portfolio. It uses a stark, clean canvas with lots of negative space, sharp typography, a monochromatic palette with one electric accent color, paired with unexpected and complex micro-interactions (like hover states revealing code or hardware-accelerated scroll effects).
_Avoid_: Generic template, slop aesthetic, standard layout

**Single-Page Architecture**:
A continuously scrolling layout where all content (Hero, Projects, Skills, Contact) flows top-to-bottom without page navigation.
_Avoid_: Multi-page routing, separate project case-study pages

**Styling & Motion Stack**:
Tailwind CSS for layout and styling, combined with Framer Motion for complex, hardware-accelerated animations and React interactions.
_Avoid_: Pure CSS animations for complex sequences, component libraries that might conflict with the custom aesthetic.

**Brand Positioning**:
Focused entirely on "Frontend Engineering" (UI/UX, React, performance). AI/Prompt Engineering projects are framed as demonstrations of building complex frontends for AI, not as prompt engineering roles.
_Avoid_: "Prompt Engineer" title, diluting the frontend focus.
